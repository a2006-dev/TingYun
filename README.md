# 停云

> 霭霭停云，濛濛时雨。

一个本地音乐挂机 App。名字取自陶渊明《停云》。

这个页面不是为了被使用，是为了被放着。

---

## 这是什么

停云把手机变成一个「正在放着音乐的房间」：雨景在动，字在淡，时间在上面走，你不需要看它。

三块屏：

| 屏 | 定位 | 说明 |
|---|---|---|
| **首页** | 配置感 | 导入歌曲、选择壁纸、调整偏好 |
| **挂机页** | 沉浸感 | 全屏播放，时钟、诗句、歌词、白噪音 |
| **导入向导** | 任务感 | 选文件、读标签、匹配歌词、入库 |

---

## 功能

### 播放

- 本地音乐播放，基于 Media3 / ExoPlayer
- 支持格式：`mp3` `flac` `m4a` `aac` `ogg` `wav` `opus`
- 曲目库本地存储，封面从音频标签读取
- 后台播放 + 媒体通知（可关）
- 熄屏常亮（可关）

### 加密格式自动转换

导入时识别并解密为普通音频：

- **NCM**（网易云）
- **QMC** 系列（QQ 音乐）：`qmc0` `qmc2` `qmc3` `qmc4` `qmc6` `qmc8` `qmcflac` `qmcogg` `mflac` `mflac0` `mgg` `mgg0` `mgg1` `mggl` `mmp4` `tkc` `bkc`

### 歌词

- 优先读取同名 `.lrc` 文件
- 缺失时联网匹配（网易云 / QQ 音乐）
- 支持中英双语，逐句高亮
- 歌词偏移可调（±5 秒）
- 可手动从候选列表里挑歌词

### 挂机页

- **四种内置场景**：雨、火、林、浪（Canvas 实时绘制，非视频）
- **三种雨景视频**：花田、便利店、车站
- **静态壁纸**：自己选图，自带裁剪页
- **白噪音**：雨声、火声、林声、浪声，音量独立
- **元素淡出**：多久后淡、淡到什么程度，都可调
- **时钟 / 日期 / 停留时长 / 随机诗句**
- 屏幕方向：横屏 / 竖屏一键切换

## 隐私

**全部本地运行。**

- 歌曲、歌词、壁纸、播放记录都只存在设备本地
- 联网只发生在两处：获取歌词、下载壁纸时（可关掉自动歌词）
- 无账号、无埋点、无统计、无广告
- 申请的权限仅用于：读文件（导入歌曲）、前台服务 + 通知（后台播放）

## 技术

```
app/src/main/
├── java/com/tingyun/app/
│   ├── MainActivity.java          主容器，WebView + ExoPlayer 桥接
│   ├── bridge/TingYunBridge.java  JS ↔ Java 接口
│   ├── data/                      Prefs、曲目库、Track 模型
│   ├── decrypt/                   NCM / QMC 解密
│   ├── lyric/                     LRC 解析、在线歌词匹配
│   ├── media/                     导入、标签读取
│   ├── player/                    ExoPlayer 封装、白噪音合成、媒体会话
│   └── wall/                      壁纸裁剪页
└── assets/
    ├── index.html                 首页
    ├── player.html                挂机页
    ├── video/                     雨景素材
    ├── sfx/                       白噪音
    └── fonts/                     霞鹜文楷子集
```

**实现要点**

- 界面是 WebView 里的 HTML/CSS/JS，播放器在原生侧，通过 `TingYunBridge` 通信
  —— 动画和排版用网页做，性能和自由度都比原生布局好；音频必须走 ExoPlayer，WebView 的 `<audio>` 播不了本地加密解出的文件
- 依赖只有四个：`media3-exoplayer`、`media3-session`、`androidx.webkit`、`appcompat`
- 内置场景用 Canvas 实时绘制，不占体积，也不消耗解码器
- 静态壁纸走自绘裁剪页，避免系统裁剪的固定比例

**构建**

```bash
./gradlew assembleRelease
```

需要自备签名配置。仓库里不含任何密钥。
